Browse all icons: [preview Energy Icons on Iconify](https://icon-sets.iconify.design/energy-icons/)

## Installation

```bash
npm install gitlab:iconify-icons/react#energy-icons
```

or
```bash
npm install github:iconify/icons-react#energy-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/energy-icons/hex-key-48';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/energy-icons/bookmark-48';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/energy-icons/brackets-48';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
