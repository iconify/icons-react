Browse all icons: [preview Quill Icons on Iconify](https://icon-sets.iconify.design/quill/)

## Installation

```bash
npm install github:iconify/icons-react#quill
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/quill/collapse';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/quill/desktop';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/quill/moon';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
