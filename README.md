Browse all icons: [preview with icons Suite on Iconify](https://icon-sets.iconify.design/withicons-suite/)

## Installation

```bash
npm install gitlab:iconify-icons/react#withicons-suite
```

or
```bash
npm install github:iconify/icons-react#withicons-suite
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/withicons-suite/home';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/withicons-suite/search';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
