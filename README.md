## Installation

```bash
npm install gitlab:iconify-icons/react#coolicons
```

or
```bash
npm install github:iconify/icons-react#coolicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/coolicons/battery-empty-duotone-round';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/coolicons/venus-fill-round';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/coolicons/apple-logo-duocolor-round';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
