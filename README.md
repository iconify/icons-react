Browse all icons: [preview Majesticons on Iconify](https://icon-sets.iconify.design/majesticons/)

## Installation

```bash
npm install github:iconify/icons-react#majesticons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/majesticons/chats-line';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/majesticons/home';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/majesticons/edit-pen-4-line';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
