**Fluent UI System Icons**

Author: [Microsoft Corporation](https://github.com/microsoft/fluentui-system-icons)

License: [MIT](https://github.com/microsoft/fluentui-system-icons/blob/main/LICENSE)

Browse all icons: [preview Fluent UI System Icons on Iconify](https://icon-sets.iconify.design/fluent/)

## Installation

```bash
npm install github:iconify/icons-react#fluent
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/fluent/zoom-out-24-filled';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/fluent/drink-coffee-24-regular';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/fluent/photo-filter-24-regular';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
