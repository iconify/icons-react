**Material Design Icons**

Author: [Pictogrammers](https://github.com/Templarian/MaterialDesign)

License: [Apache 2.0](https://github.com/Templarian/MaterialDesign/blob/master/LICENSE)

Browse all icons: [preview Material Design Icons on Iconify](https://icon-sets.iconify.design/mdi/)

## Installation

```bash
npm install github:iconify/icons-react#mdi
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/mdi/account-check';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/mdi/bell-alert-outline';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/mdi/calendar-edit';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
