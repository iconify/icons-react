## Installation

```bash
npm install github:iconify/icons-react#game-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/game-icons/diamond-trophy';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/game-icons/thrown-spear';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/game-icons/rank-3';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
