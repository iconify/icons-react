## Installation

```bash
npm install github:iconify/icons-react#fluent-emoji-high-contrast
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/fluent-emoji-high-contrast/avocado';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/fluent-emoji-high-contrast/ticket';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/fluent-emoji-high-contrast/straight-ruler';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
