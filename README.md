Browse all icons: [preview Iconito Food on Iconify](https://icon-sets.iconify.design/iconito/)

## Installation

```bash
npm install gitlab:iconify-icons/react#iconito
```

or
```bash
npm install github:iconify/icons-react#iconito
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/iconito/ice-cream';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/iconito/banana';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
