Browse all icons: [preview Akar Icons on Iconify](https://icon-sets.iconify.design/akar-icons/)

## Installation

```bash
npm install github:iconify/icons-react#akar-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/akar-icons/paper';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/akar-icons/pencil';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/akar-icons/location';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
