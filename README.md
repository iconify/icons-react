## Installation

```bash
npm install github:iconify/icons-react#cryptocurrency-color
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/cryptocurrency-color/btc';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/cryptocurrency-color/ltc';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
