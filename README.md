## Installation

```bash
npm install github:iconify/icons-react#boxicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/boxicons/clock-2-filled';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/boxicons/desk';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/boxicons/battery-filled';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
