# @iconify-react/tdesign

**TDesign Icons**

Author: [TDesign](https://github.com/Tencent/tdesign-icons)

License: [MIT](https://github.com/Tencent/tdesign-icons/blob/main/LICENSE)

Browse all icons: [preview TDesign Icons on Iconify](https://icon-sets.iconify.design/tdesign/)

## Installation

```bash
npm install github:iconify/icons-react#tdesign
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/tdesign/activity';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/tdesign/doge';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/tdesign/dam';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
