Author: **WordPress**

License: **[GPL](https://github.com/WordPress/dashicons/blob/master/gpl.txt)**

Repository: **https://github.com/WordPress/dashicons**

Browse all icons: **[Preview Dashicons](https://icon-sets.iconify.design/dashicons/)**

## Installation

```bash
npm install github:iconify/icons-react#dashicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/dashicons/shortcode';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/dashicons/businessperson';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/dashicons/editor-expand';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
