## Installation

```bash
npm install github:iconify/icons-react#f7
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/f7/hourglass-bottomhalf-fill';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/f7/pencil-outline';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/f7/rosette';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
