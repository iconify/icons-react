License: [Apache 2.0](https://github.com/material-icons/material-icons/blob/master/LICENSE)

Browse all icons: [preview Google Material Icons on Iconify](https://icon-sets.iconify.design/ic/)

## Installation

```bash
npm install github:iconify/icons-react#ic
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/ic/baseline-notifications-active';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/ic/outline-person-outline';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/ic/twotone-videocam-off';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
