## Installation

```bash
npm install github:iconify/icons-react#pajamas
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/pajamas/preferences';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/pajamas/expire';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/pajamas/merge';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
