# @iconify-react/meteor-icons

**Meteor Icons**

Author: [zkreations](https://github.com/zkreations/icons)

License: [MIT](https://github.com/zkreations/icons/blob/main/LICENSE)

Browse all icons: [preview Meteor Icons on Iconify](https://icon-sets.iconify.design/meteor-icons/)

## Installation

```bash
npm install github:iconify/icons-react#meteor-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/meteor-icons/droplet';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/meteor-icons/bolt';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/meteor-icons/flipboard';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
