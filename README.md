## Installation

```bash
npm install gitlab:iconify-icons/react#circle-flags
```

or
```bash
npm install github:iconify/icons-react#circle-flags
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/circle-flags/ee';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/circle-flags/klingon';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
