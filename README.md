**Reicon**

Author: [REICON](https://github.com/dqev/reicon)

License: [MIT](https://github.com/dqev/reicon/blob/main/LICENSE)

Browse all icons: [preview Reicon on Iconify](https://icon-sets.iconify.design/reicon/)

## Installation

```bash
npm install github:iconify/icons-react#reicon
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/reicon/ruler4';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/reicon/cart-add2-filled';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/reicon/search-normal2';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
