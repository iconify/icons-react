Browse all icons: [preview Struq Icons on Iconify](https://icon-sets.iconify.design/struq/)

## Installation

```bash
npm install gitlab:iconify-icons/react#struq
```

or
```bash
npm install github:iconify/icons-react#struq
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/struq/home';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/struq/search';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/struq/settings';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
