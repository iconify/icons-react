## Installation

```bash
npm install github:iconify/icons-react#emojione-monotone
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/emojione-monotone/face-with-tongue';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/emojione-monotone/envelope';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/emojione-monotone/frog-face';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
