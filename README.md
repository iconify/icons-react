# @iconify-react/streamline-pixel

**Pixel free icons**

Author: [Streamline](https://github.com/webalys-hq/streamline-vectors)

License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

Browse all icons: [preview Pixel free icons on Iconify](https://icon-sets.iconify.design/streamline-pixel/)

## Installation

```bash
npm install github:iconify/icons-react#streamline-pixel
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/streamline-pixel/shopping-shipping-bag-1';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/streamline-pixel/interface-essential-battery';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/streamline-pixel/social-rewards-flag';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
