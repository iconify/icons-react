## Installation

```bash
npm install gitlab:iconify-icons/react#vscode-icons
```

or
```bash
npm install github:iconify/icons-react#vscode-icons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/vscode-icons/file-type-actionscript2';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/vscode-icons/file-type-json';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
