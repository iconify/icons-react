## Installation

```bash
npm install github:iconify/icons-react#fa7-brands
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/fa7-brands/strava';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/fa7-brands/css3';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/fa7-brands/y-combinator';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
