Browse all icons: [preview Memes on Iconify](https://icon-sets.iconify.design/streamline-memes/)

## Installation

```bash
npm install gitlab:iconify-icons/react#streamline-memes
```

or
```bash
npm install github:iconify/icons-react#streamline-memes
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/streamline-memes/angry-face';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/streamline-memes/pop-cat';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/streamline-memes/pop-cat';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
