Browse all icons: [preview Stash Icons on Iconify](https://icon-sets.iconify.design/stash/)

## Installation

```bash
npm install github:iconify/icons-react#stash
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/stash/cloud-solid';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/stash/clock-duotone';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/stash/search-duotone';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
