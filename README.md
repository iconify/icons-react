# @iconify-react/prime

**Prime Icons**

Author: [PrimeTek](https://github.com/primefaces/primeicons)

License: [MIT](https://github.com/primefaces/primeicons/blob/master/LICENSE)

Browse all icons: [preview Prime Icons on Iconify](https://icon-sets.iconify.design/prime/)

## Installation

```bash
npm install github:iconify/icons-react#prime
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/prime/book';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/prime/telegram';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/prime/volume-off';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
