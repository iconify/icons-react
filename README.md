## Installation

```bash
npm install github:iconify/icons-react#basil
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/basil/comment-solid';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/basil/search-outline';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/basil/lightning-alt-solid';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
