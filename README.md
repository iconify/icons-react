## Installation

```bash
npm install gitlab:iconify-icons/react#carbon
```

or
```bash
npm install github:iconify/icons-react#carbon
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/carbon/user-certification';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/carbon/humidity';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/carbon/edit-off';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
