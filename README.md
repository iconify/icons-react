# @iconify-react/maki

**Maki**

Author: [Mapbox](https://github.com/mapbox/maki)

License: [CC0](https://creativecommons.org/publicdomain/zero/1.0/)

Browse all icons: [preview Maki on Iconify](https://icon-sets.iconify.design/maki/)

## Installation

```bash
npm install github:iconify/icons-react#maki
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/maki/entrance-alt1';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/maki/clothing-store';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/maki/grocery';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
