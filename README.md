# @iconify-react/weui

**WeUI Icon**

Author: [WeUI](https://github.com/weui/weui-icon)

License: MIT

Browse all icons: [preview WeUI Icon on Iconify](https://icon-sets.iconify.design/weui/)

## Installation

```bash
npm install github:iconify/icons-react#weui
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/weui/search-outlined';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/weui/clip-filled';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/weui/done-filled';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
