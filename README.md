## Installation

```bash
npm install gitlab:iconify-icons/react#andrsrxn
```

or
```bash
npm install github:iconify/icons-react#andrsrxn
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/andrsrxn/agent';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/andrsrxn/hashtag';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/andrsrxn/box';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
