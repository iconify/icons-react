# @iconify-react/temaki

**Temaki**

Author: [Bryan Housel](https://github.com/rapideditor/temaki)

License: [CC0](https://creativecommons.org/publicdomain/zero/1.0/)

Browse all icons: [preview Temaki on Iconify](https://icon-sets.iconify.design/temaki/)

## Installation

```bash
npm install github:iconify/icons-react#temaki
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/temaki/milestone';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/temaki/elevator';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/temaki/storage';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
