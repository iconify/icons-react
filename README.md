## Installation

```bash
npm install github:iconify/icons-react#cbi
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/cbi/mitsubishi';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/cbi/espn';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/cbi/rooms-computer';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
