# @iconify-react/pinhead

**Pinhead Map Icons**

Author: [Quincy Morgan](https://github.com/waysidemapping/pinhead)

License: [CC0](https://creativecommons.org/publicdomain/zero/1.0/)

Browse all icons: [preview Pinhead Map Icons on Iconify](https://icon-sets.iconify.design/pinhead/)

## Installation

```bash
npm install github:iconify/icons-react#pinhead
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/pinhead/a-frame-tent';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/pinhead/bird';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/pinhead/boat-on-trailer';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
