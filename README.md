## Installation

```bash
npm install gitlab:iconify-icons/react#noviair
```

or
```bash
npm install github:iconify/icons-react#noviair
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/noviair/wand';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/noviair/menu';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/noviair/summit';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
