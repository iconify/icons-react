# @iconify-react/twemoji

**Twitter Emoji**

Author: [Twitter](https://github.com/jdecked/twemoji)

License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

Browse all icons: [preview Twitter Emoji on Iconify](https://icon-sets.iconify.design/twemoji/)

## Installation

```bash
npm install github:iconify/icons-react#twemoji
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/twemoji/anguished-face';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/twemoji/duck';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
