Browse all icons: [preview Streamline on Iconify](https://icon-sets.iconify.design/streamline/)

## Installation

```bash
npm install github:iconify/icons-react#streamline
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/streamline/sign-hashtag';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/streamline/open-umbrella-solid';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/streamline/graph-bar-increase';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
