## Installation

```bash
npm install github:iconify/icons-react#emojione
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/emojione/anxious-face-with-sweat';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/emojione/cloud-with-snow';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
