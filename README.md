# @iconify-react/healthicons

**Health Icons**

Author: [Resolve to Save Lives](https://github.com/resolvetosavelives/healthicons)

License: [MIT](https://github.com/resolvetosavelives/healthicons/blob/main/LICENSE)

Browse all icons: [preview Health Icons on Iconify](https://icon-sets.iconify.design/healthicons/)

## Installation

```bash
npm install github:iconify/icons-react#healthicons
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/healthicons/cold-chain';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/healthicons/emergency-post';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/healthicons/asthma-outline';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
