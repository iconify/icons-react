## Installation

```bash
npm install github:iconify/icons-react#nrk
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/nrk/lyn';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/nrk/edit';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/nrk/mening';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
