## Installation

```bash
npm install gitlab:iconify-icons/react#wordpress
```

or
```bash
npm install github:iconify/icons-react#wordpress
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/wordpress/home';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/wordpress/pencil';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/wordpress/corner-top-right';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
