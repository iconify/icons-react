**Medical Icons**

Author: [Samuel Frémondière](https://github.com/samcome/webfont-medical-icons)

License: [MIT](https://github.com/samcome/webfont-medical-icons/blob/master/LICENSE)

Browse all icons: [preview Medical Icons on Iconify](https://icon-sets.iconify.design/medical-icon/)

## Installation

```bash
npm install github:iconify/icons-react#medical-icon
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/medical-icon/i-care-staff-area';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/medical-icon/i-nursery';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/medical-icon/immunizations';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
