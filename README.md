License: [Apache 2.0](https://github.com/Iconscout/unicons/blob/master/LICENSE)

Browse all icons: [preview Unicons Monochrome on Iconify](https://icon-sets.iconify.design/uim/)

## Installation

```bash
npm install github:iconify/icons-react#uim
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/uim/airplay';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/uim/circle-layer';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/uim/lock-access';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
