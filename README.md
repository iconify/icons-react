Browse all icons: [Preview Glyphs](https://icon-sets.iconify.design/glyphs/)

## Installation

```bash
npm install github:iconify/icons-react#glyphs
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/glyphs/mouse-2-bold';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/glyphs/object-select';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/glyphs/comment-1-duo';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
