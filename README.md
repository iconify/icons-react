**OSM Icons**

Author: [GMGeo](https://github.com/gmgeo/osmic)

License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)

Browse all icons: [preview OSM Icons on Iconify](https://icon-sets.iconify.design/osmic/)

## Installation

```bash
npm install github:iconify/icons-react#osmic
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/osmic/post-office-14';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/osmic/elevator-14';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/osmic/pub-14';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
