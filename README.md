Author: [Praveen Juge](https://github.com/praveenjuge/mynaui-icons)

License: [MIT](https://github.com/praveenjuge/mynaui-icons/blob/main/LICENSE)

Browse all icons: [preview Myna UI Icons on Iconify](https://icon-sets.iconify.design/mynaui/)

## Installation

```bash
npm install github:iconify/icons-react#mynaui
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/mynaui/signal';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/mynaui/power';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/mynaui/tree';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
