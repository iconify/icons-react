Browse all icons: [preview Iconoir on Iconify](https://icon-sets.iconify.design/iconoir/)

## Installation

```bash
npm install github:iconify/icons-react#iconoir
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/iconoir/chat-bubble-check';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/iconoir/edit';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/iconoir/activity';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
