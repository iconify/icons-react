Browse all icons: **[Preview Flag Icons](https://icon-sets.iconify.design/flag/)**

## Installation

```bash
npm install github:iconify/icons-react#flag
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/flag/fr-1x1';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/flag/de-1x1';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
