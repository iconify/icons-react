Browse all icons: **[Preview Element Plus](https://icon-sets.iconify.design/ep/)**

## Installation

```bash
npm install github:iconify/icons-react#ep
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/ep/home-filled';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/ep/partly-cloudy';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/ep/avatar';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
