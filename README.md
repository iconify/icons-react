# @iconify-react/thesvg

**theSVG**

Author: [thesvg.org](https://github.com/glincker/thesvg)

License: [MIT](https://github.com/glincker/thesvg/blob/main/LICENSE)

Browse all icons: [preview theSVG on Iconify](https://icon-sets.iconify.design/thesvg/)

## Installation

```bash
npm install github:iconify/icons-react#thesvg
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/thesvg/mitsubishi';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/thesvg/tencent';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/thesvg/vuedotjs';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
