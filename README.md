Author: [creativeLabs Łukasz Holeczek](https://github.com/coreui/coreui-icons)

License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)

Browse all icons: [preview CoreUI Flags on Iconify](https://icon-sets.iconify.design/cif/)

## Installation

```bash
npm install gitlab:iconify-icons/react#cif
```

or
```bash
npm install github:iconify/icons-react#cif
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/cif/ee';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/cif/ca';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
