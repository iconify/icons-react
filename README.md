License: **[MIT](https://github.com/box-icons/boxicons/blob/main/LICENSE)**

Repository: **https://github.com/box-icons/boxicons**

Browse all icons: **[Preview BoxIcons v2 Solid](https://icon-sets.iconify.design/bxs/)**

## Installation

```bash
npm install github:iconify/icons-react#bxs
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/bxs/edit-alt';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/bxs/tree-alt';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/bxs/circle-half';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
