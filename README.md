**Cyber color icons**

Author: [Streamline](https://github.com/webalys-hq/streamline-vectors)

License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

Browse all icons: [preview Cyber color icons on Iconify](https://icon-sets.iconify.design/streamline-cyber-color/)

## Installation

```bash
npm install github:iconify/icons-react#streamline-cyber-color
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/streamline-cyber-color/shopping-basket-3';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/streamline-cyber-color/command-2';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
