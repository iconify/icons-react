# @iconify-react/wpf

**Icons8 Windows 8 Icons**

Author: [Icons8](https://github.com/icons8/WPF-UI-Framework)

License: MIT

Browse all icons: [preview Icons8 Windows 8 Icons on Iconify](https://icon-sets.iconify.design/wpf/)

## Installation

```bash
npm install github:iconify/icons-react#wpf
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/wpf/check-file';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/wpf/add-image';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/wpf/geo-fence';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
