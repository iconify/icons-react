Browse all icons: [preview Nimbus on Iconify](https://icon-sets.iconify.design/nimbus/)

## Installation

```bash
npm install github:iconify/icons-react#nimbus
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/nimbus/barcode';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/nimbus/mail';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/nimbus/calendar';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
