Browse all icons: [preview Mono Icons on Iconify](https://icon-sets.iconify.design/mi/)

## Installation

```bash
npm install github:iconify/icons-react#mi
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/mi/bar-chart';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/mi/cloud-upload';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```

To change icon color, use style:

```jsx
import SampleIcon from '@iconify-react/mi/log-out';

function Test() {
  return (
    <SampleIcon style={{color: 'red'}} />
  );
}
```
