**UnJS Logos**

Author: [UnJS](https://github.com/unjs)

License: Apache 2.0

Browse all icons: [preview UnJS Logos on Iconify](https://icon-sets.iconify.design/unjs/)

## Installation

```bash
npm install github:iconify/icons-react#unjs
```

## Usage

For full documentation visit [Iconify website](https://iconify.design/docs/usage/svg-css/react/).

Few usage examples:

```jsx
import SampleIcon from '@iconify-react/unjs/nitro';

function Test() {
  return (
    <SampleIcon />
  );
}
```

To resize icon, set `width` and/or `height` parameters:

```jsx
import SampleIcon from '@iconify-react/unjs/jiti';

function Test() {
  return (
    <SampleIcon height="1em" />
  );
}
```
